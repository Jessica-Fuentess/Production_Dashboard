# 📊 Dashboard de Produção | Power BI

Este projeto apresenta um **Dashboard de Produção** desenvolvido no **Power BI**, com foco no monitoramento de desempenho operacional, produtividade, qualidade e eficiência industrial.  
O painel foi construído para apoiar a **análise de dados produtivos**, identificação de gargalos e suporte à tomada de decisão baseada em indicadores (KPIs).

---

## 🎯 Objetivo do Projeto

O objetivo deste dashboard é fornecer uma visão clara e consolidada da produção, permitindo:

- Acompanhar volumes aprovados e rejeitados
- Monitorar horas produtivas e horas paradas
- Avaliar eficiência operacional e qualidade
- Analisar desempenho ao longo do tempo
- Identificar pontos críticos para melhoria contínua

---

## 🧩 Principais Indicadores (KPIs)

- **Total Aprovado**
- **Total Rejeitado**
- **Horas Produtivas**
- **Horas Paradas**
- **Disponibilidade (%)**
- **Qualidade (%)**

---

## 📈 Análises e Visualizações

O dashboard conta com os seguintes elementos visuais:

- 📊 **Evolução do Total Aprovado por Mês**
- ⏱️ **Indicadores de Horas Produtivas vs. Horas Paradas**
- 🧮 **Indicadores de Disponibilidade**
- ✅ **Indicador de Qualidade**
- 🎛️ **Filtros dinâmicos por Operador e Mês**

Essas visualizações permitem uma análise rápida e intuitiva do desempenho da produção, facilitando comparações e identificação de tendências.

---

## 🛠️ Ferramentas Utilizadas

- **Power BI**
- **Power Query** para tratamento e transformação dos dados
- **DAX** para criação de medidas e KPIs
- **Excel** como fonte de dados

---

## 🔍 Tratamento de Dados

Durante o desenvolvimento, foram aplicadas as seguintes etapas:

- Limpeza e padronização dos dados
- Tratamento de valores inconsistentes
- Criação de medidas calculadas em DAX
- Organização do modelo de dados para melhor performance
